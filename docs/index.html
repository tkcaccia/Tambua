CellPhenotyper · GigaTIME · fastPLS 0.4

Cell identity from virtual tissue markers

Tambua quantifies H&E-derived GigaTIME marker scores in individual cells, then assigns cell types with a patient-disjoint fastPLS classifier. Every cell keeps its source image, physical resolution and instance identity.

01 · Image

Read the physical scale

OME micrometres-per-pixel metadata determine resampling. A 0.325 µm/pixel image is mapped to GigaTIME’s 0.25 µm/pixel inference grid before marker generation.

02 · Cells

Keep instance IDs aligned

CellPhenotyper quantifies all 23 virtual channels over nuclei, cytoplasm or whole-cell masks. Tambua joins tables by sample and positive cell ID, never by row order.

03 · Identity

Fit fastPLS 0.4

GitHub fastPLS 0.4 fits a SIMPLS–LDA model to independently annotated training cells. Training and evaluation patients must be disjoint.

What the scores mean

GigaTIME produces virtual staining scores from H&E. They are useful model inputs but are not measured protein abundance or calibrated probabilities. Tambua’s cell-type labels are research predictions.

Alignment gate. The predicted DAPI image must visibly coincide with H&E nuclei. We also record a numerical overlap with an H&E nuclear proxy. This checks spatial plausibility; it does not establish biological cell-type accuracy.

Inputs and outputs

  • Calibrated H&E image plus cell instance mask.
  • Per-cell GigaTIME scores from CellPhenotyper, with stable label_id.
  • Independent training annotations and patient IDs.
  • A fitted .rds fastPLS model, feature sidecar, cell predictions and held-out evaluation report.

Run the classifier

Install R 4.6 or newer and the pinned GitHub fastPLS 0.4 source using the repository instructions. Then build the per-cell table and fit on annotated patients.

tambua build-table --manifest specimens.csv --output results/cells.csv --compartments cell
tambua train --table results/cells.csv --model results/cell_classifier.rds --report results/test_report.json
tambua build-inference --manifest new_specimens.csv --output results/new_cells.csv --compartments cell
tambua predict --table results/new_cells.csv --model results/cell_classifier.rds --output results/predictions.csv
